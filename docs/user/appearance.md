# Appearance

Open **Settings** and select **Appearance**.

## Accent color

The accent is the color of primary buttons, the focus ring, and the send action. Select one of the
swatches beside **Accent colour**, or **Custom** to pick any color. Select **Reset** to hand the
accent back to whichever theme is active.

A color you pick keeps its hue but is adjusted to the lightness the interface expects of an accent,
separately for light and dark, so a very pale or very dark choice still reads as a button rather
than disappearing into the surface. The label color on top of it is chosen to stay readable.

An accent set here applies over the accent of the theme you are using, including custom themes,
until you reset it.

## Glass opacity

Controls how transparent glass surfaces are. Higher values make menus, dialogs, and the composer
more solid.

## Themes

The theme library offers built-in themes and any you have imported, with separate light and dark
halves. The floating theme editor is opened from **Settings** → **Keybindings** with
`themeEditor.toggle`, and lets you edit individual colors and inspect which element uses which.
